## 사용 방법

- 첫 화면 하단의 **추가**로 장비를 등록합니다. 목록에서 장비를 선택하면 **수정**, **삭제**, **접속**을 사용할 수 있습니다.
- PC를 등록하려면 원격 PC의 OneViewer PC Agent 1.8.103에서 화면 공유를 시작한 뒤, 앱에서 **추가 → PC Agent 등록**을 선택합니다. 이름, DDNS 또는 IP, 비밀번호를 입력하고 등록한 PC에 접속합니다.
- DVR/NVR 실시간 보기에서 **PC** 버튼을 누르면 세로 화면에서 CCTV와 PC 화면을 함께 볼 수 있습니다. 세로로 돌아올 때 PC 연결이 이어집니다.
